# Checkliste vor der Veranstaltung

Eine Seite. Ausdrucken, abhaken, dann anfangen. Das Handbuch steht in
[HANDBUCH.de.md](HANDBUCH.de.md).

---

## A — Ein paar Tage vorher, zu Hause

- [ ] WattMatt ist auf **dem** Laptop, der am Abend im Einsatz ist — nicht auf einem anderen.
- [ ] Das Programm wurde auf diesem Laptop **schon einmal gestartet**, und die Warnung
      *Der Computer wurde durch Windows geschützt* wurde über **Weitere Informationen** →
      **Trotzdem ausführen** einmal bestätigt. Danach kommt sie nicht wieder.
- [ ] Ein **Probeturnier mit vier Gruppen** ist einmal komplett durchgespielt worden: anlegen,
      auslosen, Sieger festlegen, Runde abschließen, Namen erfassen, Turnierbaum, Siegerehrung.
- [ ] Der Laptop hat den **Beamer schon einmal gesehen** — mit demselben Kabel und demselben
      Adapter wie am Veranstaltungstag.
- [ ] Ersatzkabel und Adapter liegen in der Tasche.

## B — Aufbau im Saal

- [ ] Laptop hängt am **Netzteil**, und das Netzteil steckt in einer Steckdose, die niemand mit
      dem Fuß erwischt.
- [ ] Beamer angeschlossen und eingeschaltet, Bild ist auf der Leinwand zu sehen.
- [ ] Windows steht auf **Erweitern** (Windows-Taste + P → *Erweitern*), **nicht** auf
      *Duplizieren*.
- [ ] Auflösung des zweiten Bildschirms steht auf dem vom Beamer empfohlenen Wert.
- [ ] **Energiesparmodus abgeschaltet:** Windows-Einstellungen → *System* → *Netzbetrieb und
      Energiesparen* → Bildschirm und Energiesparmodus auf **Nie**. WattMatt hält den
      Bildschirm zwar selbst wach, solange der Beamer läuft — aber verlassen Sie sich nicht
      allein darauf.
- [ ] **Bildschirmschoner aus.**
- [ ] Benachrichtigungen aus: Windows-Einstellungen → *System* → *Benachrichtigungen* →
      **Nicht stören** ein. Sonst schiebt sich mitten im Finale ein Hinweisfenster ins Bild.
- [ ] Alle anderen Programme geschlossen.

## C — In WattMatt, vor dem ersten Anpfiff

- [ ] Turnier **angelegt und benannt**. Der Name steht auf der Leinwand.
- [ ] **Teilnehmer-Bezeichnung** gewählt: *Gruppe*, *Team* oder *Spieler*.
- [ ] **Namen ab Feldgröße** geprüft (Voreinstellung 16). Ab der Namenserfassung ist der Wert
      gesperrt.
- [ ] **Alle Tische angelegt** — so viele, wie tatsächlich im Saal stehen — und so benannt, wie
      sie im Saal beschriftet sind.
- [ ] Nicht bespielbare Tische **gesperrt**, nicht gelöscht.
- [ ] **Alle Teilnehmenden angelegt.** Anzahl noch einmal gegen die Anmeldeliste zählen.
- [ ] **Prüfung vor dem Start** meldet *Alles bereit. Das Turnier kann gestartet werden.*
- [ ] Steht dort ein Hinweis auf **wartende Partien** (weniger Tische als Partien): gelesen und
      in Ordnung.
- [ ] Steht dort ein Hinweis auf ein **Freilos** (ungerade Zahl): gelesen und in Ordnung — oder
      es kommt noch jemand dazu.

## D — Beamer, unmittelbar vor Beginn

- [ ] Beamer-Fenster ist offen, Statuszeile meldet **Beamer läuft im Vollbild.**
- [ ] **Bildkanal** meldet *Beamer meldet sich.*
- [ ] Das **Willkommen**-Bild (Ziffer `1`) liegt auf der Leinwand und die Zahl darauf stimmt.
- [ ] **Bildschirm aus** einmal ausprobiert: `B` drücken, Leinwand wird schwarz, `B` drücken,
      Bild ist zurück.
- [ ] Auf der Leinwand ist von **hinten in der letzten Reihe** lesbar, was dort steht. Wenn
      nicht: näher an die Leinwand oder Raum abdunkeln.
- [ ] Bei träger Darstellung: **Performance-Modus** in den Turniereinstellungen einschalten.
- [ ] Das Steuerfenster ist auf dem **Laptop-Bildschirm** und nicht auf der Leinwand.

## E — In Reichweite

- [ ] Diese Checkliste und die Seite [Wenn etwas nicht funktioniert](PROBLEME.de.md) liegen
      ausgedruckt neben dem Laptop.
- [ ] Die Anmeldeliste liegt daneben — Nummer und Name je Teilnehmenden.
- [ ] Sie wissen, wo **Strg+Z** ist, und dass es jeden Fehlklick zurücknimmt.
- [ ] Sie haben entschieden, ob es an diesem Abend eine **Trostrunde** gibt, und — falls ja —
      welche **Tische** dafür gedacht sind. WattMatt fragt danach, sobald die Hoffnungsrunde
      abgeschlossen ist.
- [ ] Sie wissen, dass **B** die Leinwand sofort schwarz macht.

---

**Die drei Punkte, die am häufigsten fehlen:** Netzteil, *Erweitern* statt *Duplizieren*, und
Energiesparmodus auf *Nie*.
