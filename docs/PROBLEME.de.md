# Wenn etwas nicht funktioniert

Eine Seite. Ausdrucken und neben den Laptop legen. Ausführlich steht alles im
[Handbuch](HANDBUCH.de.md).

> **Zuerst, immer:**
> **B** macht die Leinwand sofort schwarz — für alles, was das Publikum nicht sehen soll.
> **Strg+Z** nimmt den letzten Klick zurück — für alles, was Sie nicht klicken wollten.
> Beides ist gefahrlos und jederzeit umkehrbar. **Atmen. Nichts geht verloren.**

---

## Die Leinwand

| Was Sie sehen | Was zu tun ist |
| --- | --- |
| **Leinwand ist schwarz und soll es nicht sein.** | Steht in der rechten Spalte **Bildschirm wieder an**? Dann ist *Bildschirm aus* eingeschaltet — Knopf drücken oder `B`. Sonst: Beamer eingeschaltet? Richtige Quelle am Beamer gewählt? Kabel? |
| **Leinwand zeigt ein altes Bild und ändert sich nicht.** | Steht *Eingefroren* über Ihrer Vorschau? Dann **Bild freigeben** oder `F`. |
| **Statuszeile meldet *Beamer meldet sich nicht*.** | Das Fenster hängt. **Beamer schließen**, dann **Beamer öffnen**. Am Turnier ändert das nichts, das Bild kommt genauso zurück. |
| **Das Beamer-Bild liegt über Ihrer Steuerung** (*Beamer läuft im Vollbild auf dem Laptop-Bildschirm*). | Der falsche Bildschirm wurde gewählt. **Alt + Tabulatortaste** bis das Steuerfenster vorne ist, oder **Steuerung nach vorne holen** — dann unter **Bildschirm** den richtigen anklicken. |
| **Auf der Leinwand ist Ihre Steuerung zu sehen.** | Windows steht auf *Duplizieren*. Windows-Taste + P → **Erweitern**. Danach in WattMatt den zweiten Bildschirm anklicken. |
| **Kein Bild auf der Leinwand, Statuszeile meldet *Kein zweiter Bildschirm gefunden*.** | Kabel prüfen, danach in der Liste unter **Bildschirm** den Beamer anklicken. Die Liste aktualisiert sich von selbst. |
| **Statuszeile meldet *Der gewählte Bildschirm ist nicht mehr da*.** | Das Kabel hat sich gelöst. Sobald es wieder steckt, geht das Bild zurück auf die Leinwand. |
| **Bild mit schwarzen Balken.** | Die Leinwand ist nicht 16:9. Kein Fehler — lieber Balken als ein abgeschnittener Turnierbaum. |
| **Die Leinwand ruckelt.** | Turniereinstellungen → **Performance-Modus** einschalten. Jederzeit umschaltbar. |
| **Bildschirmschoner oder Ruhezustand kommt.** | Windows-Einstellungen → *System* → *Netzbetrieb und Energiesparen* → Bildschirm und Energiesparmodus auf **Nie**. |
| **Eine Ansicht ist grau und nicht anklickbar.** | *Auslosung* und *Runde* gibt es erst nach der ersten Auslosung. |
| **Ein Bild wechselt von selbst.** | **Automatisch folgen** ist eingeschaltet. Ausschalten, dann bleibt Ihre Ansicht stehen. |

## Falsch geklickt

| Was passiert ist | Was zu tun ist |
| --- | --- |
| **Falschen Sieger angeklickt** (Runde). | Auf der Karte **Ergebnis ändern**, dann den richtigen Sieger. Oder **Strg+Z**. |
| **Falschen Sieger angeklickt** (Turnierbaum), spätere Partien schon gespielt. | **Ergebnis ändern**. WattMatt listet auf, welche Ergebnisse dadurch verworfen werden — lesen, dann **Ändern und verwerfen**. Auch das lässt sich mit **Strg+Z** komplett zurücknehmen. |
| **Zu früh ausgelost.** | **Strg+Z**. Die Auslosung ist weg, die Tische sind wieder frei. |
| **Runde zu früh abgeschlossen.** | **Strg+Z**. |
| **Falsch auf *Verzichtet* geklickt** (Hoffnungsrunde). | **Strg+Z**. Oder, wenn es schon länger her ist: **Ausgeschiedene erneut zulassen**, sobald der Topf leer ist. |
| **Tisch versehentlich gelöscht.** | **Strg+Z**. |
| **Falschen Namen erfasst.** | Einfach überschreiben. Namen lassen sich jederzeit ändern. |
| **Der Rückgängig-Knopf ist grau.** | *Der Verlauf beginnt beim geöffneten Turnier.* Nach einem Schließen und Öffnen ist er leer. Die Ergebnisse selbst sind alle da; korrigieren Sie über **Ergebnis ändern**. |
| **Ein Knopf ist grau.** | Der Grund steht auf dem Knopf selbst, zum Beispiel *3 Partien ohne Sieger*. Lesen und beheben. |
| **Die Tastenkürzel wirken nicht.** | Sie stehen in einem Textfeld. Klicken Sie irgendwo daneben — dann greifen sie wieder. |

## Programm und Dateien

| Was passiert ist | Was zu tun ist |
| --- | --- |
| **WattMatt ist abgestürzt oder der Strom war weg.** | Neu starten. WattMatt bietet **Turnier wiederherstellen** an — ein Klick, und Sie sind zurück. Es fehlt höchstens die eine Entscheidung, die im Moment des Absturzes gefallen ist. |
| **Die Steuerung zeigt *WattMatt hat einen Fehler*.** | **Erneut versuchen** drücken. Das geöffnete Turnier bleibt dabei erhalten. |
| **Eine Meldung erscheint rechts unten.** | Sie sagt immer, was zu tun ist. Sie geht nicht von selbst weg, verdeckt aber auch nichts. **Ausblenden**, wenn erledigt. |
| **Turnierdatei lässt sich nicht öffnen** (*konnte nicht gelesen werden* / *passt nicht zum erwarteten Format*). | **Letzte Sicherung öffnen** anklicken — WattMatt bietet das direkt an. Neben jeder Turnierdatei liegen bis zu drei Sicherungen, `.bak1` ist die jüngste. |
| **Meldung: *Diese Datei stammt aus einer neueren Version von WattMatt*.** | Die Sicherungen helfen hier nicht. Öffnen Sie das Turnier auf dem Gerät mit der neueren Fassung. |
| **Meldung: *Die Turnierdatei ist an diesem Ort nicht mehr vorhanden*.** | Der USB-Stick oder die Festplatte ist weg. Wieder anstecken, dann **Speichern unter…** auf die eingebaute Festplatte. |
| **Meldung: *Auf die Turnierdatei darf nicht zugegriffen werden*.** | Ein anderes Programm hat sie offen. Schließen und erneut speichern. |
| **Meldung: *Das Turnier wird gerade nicht automatisch gespeichert*.** | Sofort **Speichern unter…**, Speicherort auf der eingebauten Festplatte wählen. Nicht bis später warten. |
| **Doppelklick auf eine Turnierdatei tut nichts.** | Ist bereits ein anderes Turnier offen, wird es nicht ersetzt — das ist Absicht. Aktuelles Turnier zuerst schließen. |
| **Doppelklick öffnet WattMatt gar nicht.** | Sie verwenden die Fassung ohne Installation. Diese trägt sich nicht in Windows ein. Öffnen Sie im Programm über **Turnier öffnen**. |
| **Beim Start kommt *Der Computer wurde durch Windows geschützt*.** | **Weitere Informationen** → **Trotzdem ausführen**. Einmalig, danach nie wieder. |
| **Meldung: *Der Energiesparmodus konnte nicht abgeschaltet werden*.** | Von Hand: Windows-Einstellungen → *System* → *Netzbetrieb und Energiesparen* → Bildschirm und Energiesparmodus auf **Nie**. |
| **Meldung: *Der Vermerk für die Wiederherstellung … konnte nicht geschrieben werden*.** | Speichern Sie zwischendurch von Hand über **Turnier speichern**. |

## Wenn gar nichts mehr hilft

1. **B** — die Leinwand wird schwarz, das Publikum sieht nichts Peinliches.
2. **Turnier speichern**, falls der Knopf reagiert.
3. WattMatt beenden und neu starten. Beim Start das Turnier wiederherstellen oder über
   *Zuletzt verwendet* öffnen.
4. Läuft es danach immer noch nicht: **Protokoll öffnen** (ganz unten in der rechten Spalte)
   und den Ordner `%APPDATA%\WattMatt\logs` weitergeben. Er hilft der Entwicklung, den Fehler
   zu finden. Ihr Turnier steht dort nicht drin — das liegt in der `.wattmatt`-Datei.

Und im Notfall: Die Turnierdatei ist reiner Text. Sie lässt sich mit dem Editor öffnen und im
schlimmsten Fall von Hand ablesen, wer schon gespielt hat.
